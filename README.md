## Sobre

Estudante de Engenharia de Computação na UEMG, com base técnica em redes e
infraestrutura. Hoje trabalho com aplicações web e mobile — React no front,
Flutter no mobile, Python quando o problema pede processamento de dados.

Interesse particular em projetos onde software encosta no hardware: a formação
em redes me deixou confortável com a camada que a maioria dos devs prefere
ignorar.

- Atualmente estudando **TypeScript** e arquitetura de aplicações
- Aberto a oportunidades de **estágio e projetos colaborativos**
- Contato mais rápido pelo **WhatsApp** ou **LinkedIn**
